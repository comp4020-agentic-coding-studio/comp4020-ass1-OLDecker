The breakthrough for me was how fast you can go from a complex topic to something people can actually understand. Protein folding is not a simple idea, but building it as a small interactive website meant I could explain the general idea of it in a way that's easy to grasp, and I could do that in not a lot of time at all. Seeing an agent help turn a dense topic into something clickable and understandable that quickly was the moment this project really started moving.

It also changed a couple of things about how I want to work as a developer. The first is around control and pacing. When I was running a bit short on time, I found it hard to stay in control of how fast the agent was moving. It has its own speed, and matching that to how much time I actually had was harder than I expected. I want to get better at directing that pace myself instead of just following along with it.

The second thing is about trust and testing. It's easy to add a new feature and assume it works because the code runs, but I can't actually claim a feature works as intended until I've tested it thoroughly. Some features were genuinely tricky to implement well for that reason: writing something that looks right is not the same as knowing it behaves correctly. This pushed me toward wanting to be a developer who verifies things properly before calling them finished, rather than one who assumes it's fine because it compiled or looked okay at a glance.
